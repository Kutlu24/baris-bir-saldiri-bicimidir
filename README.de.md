# Barış Bir Saldırı Biçimidir

Ein persönliches Manifest-/Kunstprojekt als Ein-Seiten-Website: „Frieden als Angriffsform" — die Idee, dass beharrliche, bewusste Akte der Diplomatie, Empathie und kulturellen Zusammenarbeit ebenso strategisch und unnachgiebig sein können wie ein Angriff. Es ist ein Meinungsbeitrag / eine künstlerische Aussage, keine Nachrichten- oder politische Organisationsseite.

🇬🇧 English version: [README.md](README.md)

## Inhalt

- `index.html` — Startseite mit Endlos-Hintergrundvideo und Call-to-Action.
- `manifesto.html` — der vollständige Manifest-Text.
- `style.css` — gemeinsames Styling.
- `videos/your-peace-video.mp4` — Hintergrundvideo.

## Technik

Reines HTML/CSS mit einem kleinen Inline-JS-Snippet für das mobile Navigationsmenü. Google Fonts (Poppins) und Font Awesome per CDN. Kein Build-Prozess, kein Backend.

## Ausführen

`index.html` im Browser öffnen, oder den Ordner mit einem beliebigen statischen Server bereitstellen:

```bash
npx serve .
```

## Hinweis

Einige Navigationslinks (`#nasil-katilirim`, `#arsiv`, `#kendi-saldirini-baslat`, `#iletisim`) sind Platzhalter für nie umgesetzte Abschnitte — die Seite besteht nur aus Hero- und Manifest-Seite.
