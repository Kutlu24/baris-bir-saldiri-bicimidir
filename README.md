# Barış Bir Saldırı Biçimidir

A personal manifesto/art project presented as a single-page website: "peace as a form of attack" — the idea that persistent, deliberate acts of diplomacy, empathy, and cultural exchange can be as strategic and unrelenting as an attack. It's an opinion piece / creative statement, not a news or political organization site.

🇩🇪 German version: [README.de.md](README.de.md)

## What's here

- `index.html` — landing page with a looping background video and a call to action.
- `manifesto.html` — the full manifesto text.
- `style.css` — shared styling.
- `videos/your-peace-video.mp4` — background video.

## Tech stack

Plain HTML/CSS with a small inline JS snippet for the mobile nav toggle. Google Fonts (Poppins) and Font Awesome loaded via CDN. No build step, no backend.

## Running it

Open `index.html` in a browser, or serve the folder with any static file server:

```bash
npx serve .
```

## Note

Several nav links (`#nasil-katilirim`, `#arsiv`, `#kendi-saldirini-baslat`, `#iletisim`) are placeholders for sections that were never built out — the site is the hero/manifesto pages only.
